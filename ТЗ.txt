
ТЕХНИЧЕСКОЕ ЗАДАНИЕ: TickTask

1. Зависимости: все библиотеки перечислены в requirements.txt

2. Фронтенд: используется Bootstrap для адаптивного интерфейса

3. ORM: реализованы модели пользователь и задача с необходимыми связями

4. Аутентификация: реализована регистрация, авторизация и выход из системы

5. Файлы: реализована возможность загрузки и хранения файлов, привязанных к задачам

6. API: используется стороннее API (Groq) для работы искусственного интеллекта

7. Хранение данных: данные хранятся в базе данных SQLite через SQLAlchemy

8. Хостинг: приложение развёрнуто на хостинге replit.com: https://tick-task--Lev223.replit.app

9. Быстрый ввод задач: пользователь вводит задачи через текстовые формы

10. ИИ-парсинг: искусственный интеллект автоматически определяет категорию, важность и предполагаемую длительность из текста задачи

11. Сортировка по важности: реализована автоматическая сортировка задач на главной странице по приоритету и статусу завершения

12. Умное планирование: искусственный интеллект генерирует персонализированный план дня на основе списка активных задач

13. Контроль задач: реализована система управления статусом задач (выполнено/не выполнено)

14. Статистика: ведется автоматический учет и расчет процента продуктивности пользователя на основе завершенных дел
